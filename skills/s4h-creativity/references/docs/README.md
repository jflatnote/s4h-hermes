# 💡 Creativity

> *The dominant idea is the enemy of the next idea.*

---

## What this category is

The creativity toolkit is the full de Bono suite — twelve structured techniques for generating, exploring, evaluating, and escaping fixed thinking. These aren't brainstorming variations; they're distinct tools with specific jobs:

- Some **generate** options (Alternatives, Concept Fan, Random Entry)
- Some **evaluate** options (PMI, Six Hats, Consider All Factors)
- Some **escape** fixed positions (Lateral Thinking, Assumption Excavator, Provocation)
- Some **explore** territory without judgment (Water Logic, Other Perspectives)
- One **orchestrates** the others for comprehensive sessions (Brainstorm)

The hardest part of creative thinking isn't generating ideas — it's knowing which tool to apply to which situation. The `skill_view(name="s4h-creativity")` command handles that.

---

## When to reach for it

- Stuck on a problem and keep returning to the same direction
- About to make a decision and want to make sure you've seen all the options
- Need to evaluate a specific idea fairly, without snap judgment
- Want a comprehensive multi-perspective analysis before committing
- Problem framing itself might be wrong
- Need a jolt from outside the problem space
- Want to think through how others will respond to a decision

---

## When *not* to reach for it

**Creativity tools are for generating and exploring, not for validating.** If you need to know whether something is logically sound, that's [Logic](https://github.com/human-avatar/skills-for-humanity/blob/main/docs/logic). If you need to know whether it's ethical, that's [Ethics](https://github.com/human-avatar/skills-for-humanity/blob/main/docs/ethics).

**Don't reach for creativity when the problem is an information gap.** No amount of creative thinking replaces missing data. Get the information first, then think creatively with it.

The nearest neighbor: [Play](https://github.com/human-avatar/skills-for-humanity/blob/main/docs/play) — which also generates unconventional ideas, but through inversion, reversal, and deliberate absurdity rather than the structured de Bono toolkit.

| **`skill_view(name="s4h-creativity")`** | Routes to the right creativity skill for your situation | Not sure which tool fits; describe your situation |

| [`skill_view(name="s4h-creativity", file_path="references/lateral-thinking.md")`](lateral-thinking.md) | Escapes dominant patterns to generate genuinely new directions | Stuck on one approach; keep returning to the same idea; "I need to think differently" |
| [`skill_view(name="s4h-creativity", file_path="references/alternatives.md")`](alternatives.md) | Generates all options before evaluating any (APC) | About to decide; want to see the full option set first |
| [`skill_view(name="s4h-creativity", file_path="references/concept-fan.md")`](concept-fan.md) | Expands the solution space at multiple levels of abstraction | Locked into one solution; want to see the full range of approaches |
| [`skill_view(name="s4h-creativity", file_path="references/six-hats.md")`](six-hats.md) | Structured parallel thinking from six distinct angles | Need full multi-perspective analysis; preparing for a meeting; want both optimism and caution |

| [`skill_view(name="s4h-creativity", file_path="references/other-perspectives.md")`](other-perspectives.md) | Thinks genuinely from other people's positions (OPS) | Decision affects others; want to anticipate how they'll respond; in a negotiation |
| [`skill_view(name="s4h-creativity", file_path="references/water-logic.md")`](water-logic.md) | Explores without premature judgment | Early-stage exploration; premature categorization is killing promising directions |
| [`skill_view(name="s4h-creativity", file_path="references/random-entry.md")`](random-entry.md) | Uses an unrelated stimulus to break cognitive fixation | Thoroughly stuck; "I've exhausted my usual thinking"; need a jolt from outside |
| [`skill_view(name="s4h-creativity", file_path="references/provocation.md")`](provocation.md) | Uses an impossible premise as a springboard to new ideas | Need a deliberate jolt into the impossible; "Po:" prefix on a statement |
| [`skill_view(name="s4h-creativity", file_path="references/consider-factors.md")`](consider-factors.md) | Maps every relevant factor before deciding or acting (CAF) | About to act; want a complete pre-flight checklist; don't want to be surprised |

**Not sure which tool?** → Invoke `skill_view(name="s4h-creativity")` — it diagnoses your situation and picks the right skill.
